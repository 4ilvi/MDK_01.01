# Жизненный цикл разработки ПО (SDLC)

#### Software Development Life Cucle
Жизненный цикл — это путь, который проходит продукт: от момента задумки до вывода из эксплуатации (*смерти*)

Этапы ЖЦПО: 
+ Планирование и анализ требований
    1.	Описание задач, которые должен решать продукт;
    2.	Опрос стейкхолдеров;
    3.	Выявление аудитории продукта;
    4.	Оценка ресурсов для реализации;
    5.	Согласование критериев оценки;
+	Определение требований
    1.	Оценка рисков;
    2.	Выбор методологии работы;
    3.	Описание пользовательских сценариев;
+	Проектирование
    Верхнеуровневое проектирование	Низкоуровневое проектирование
    Основные компоненты проектирования системы - модуль, сервисы, подсистемы	Принцип работы отдельных компонентов системы
    Принцип взаимодействия этих компонентов между собой	Алгоритм, структуры данных и логики работы внутри каждого модуля
    Общая архитектура системы - клиент-серверная архитектура или микросервисы	Детали реализации - какие классы, методы или функции будут созданы
    Зависимость решения от других систем	Взаимодействие с базами данных, API или другими внешними системами
    Прототип интерфейса	

+	Разработка
+	Тестирование 
+	Развёртывание
+	Поддержка и сопровождение
+	«*Смерть*» ПО - вывод из эксплуатации
