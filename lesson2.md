# Введение в С++

## язык программирования C++ 

 + Язык программирования c++ представляет высокоуровневый компилируемый язык программирования общего назначения со статической типизацией

  Своими корнями он уходив в язык C который был разработан 1969-1973гг. компании _Bell labs_ программистом *Деннисом Ритчи*<br>

  В начале 1980 годов датский программист Бьерн Страуструп который в то время работал в компании разработал C++, как расширение к языку C, фактически изначально C++ просто дополнял C с некоторыми возможностями ООП 

>_Изначально язык назывался "C с классами"_<br>

  C++ является компилируемым языком, а это значит что компилятор транслирует исходный код на C++ в исполняемый файл, который содержит набор машинных инструкций

### Основные компиляторы

### Зачем нужно компилировать исходные файлы

  Исходный C++ файл это всего лишь код, но его не возможно запустить как программу или использовать как библиотеку, поэтому каждый исходный файл требуется скомпилировать в исполняемый<br>

### Этапы компиляции
1. **Препроцессинг** - это макропроцессор который преобразовывает программу для дальнейшего компилирования. На данной стадии происходит работа с препроцессорными директивами.<br>
Например, препроцессор добавляет хедеры в код(#include), убирает комментарии.
2. **Компиляция** - преобразует в ассемблерный код. Это промежуточный шаг между высокоуровневым языком и машинным кодом
3. **Ассемблирование** - перевод ассемблерного кода в машинный.<br>
   Объектный файл - это созданный ассемблером промежуточный файл хранящий кусок машинного кода, это кусок который ещё не был связан с другими кусками машинного кода, называется ****объектным кодом****
4. **Компоновка** - Компоновщик(линкер) связывает все объектные файлы и статические библиотеки в единый исполняемый файл, который мы можем запустить
5. **Загрузка**
