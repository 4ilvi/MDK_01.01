# Введение в С++

## язык программирования C++ 

 + Язык программирования c++ представляет высокоуровневый компилируемый язык программирования общего назначения со статической типизацией

своими корнями он уходив в язык C который был разработан 1969-1973гг. компании _Bell labs_ программистом *Деннисом Ритчи*<br>

В начале 1980 годов датский программист Бьерн Страуструп который в то время работал в компании разработал C++, как расширение к языку C, фактически изначально C++ просто дополнял C с некоторыми возможностями ООП 

 >_Изначаль язык назывался "C с классами"_

C++ является компилируемым языком, а это значит что компилятор транслирует исходный код на C++ в исполняемый файл, который содержит набор машинных инструкций
